# CADmium — precision, from every angle

A continuous mechanical assembly story and local CAD inspection workspace, evolved from this project's earlier FORMA viewer. React + strict TypeScript + Three.js + GSAP ScrollTrigger. **[Open CADmium](http://127.0.0.1:4326)** · **[Open viewer directly](http://127.0.0.1:4326/#viewer)**.

## Viewer tools

- Orbit, pan, zoom, fit and camera/assembly reset.
- Front, back, left, right, top, bottom, isometric; perspective and orthographic.
- Solid, wireframe, edge-overlay, matte/clay and X-ray modes; background color, grid and axes.
- Separate Studio/Inspect lighting and material policies; whole-model/selected-component finishes, documented presets and Restore original appearance.
- Selected-component transparency, selection highlighting, tree visibility, hide selected, isolate and show all.
- Mesh-derived bounds, triangle count and available metadata.
- Exploded slider only for actual separate mesh components. A single STL is not assigned invented components.
- Picked surface-point distance with visible endpoints, line, units and clearing points.
- X/Y/Z adjustable clipping plane with reset; **uncapped mesh clipping**, not sectioned B-rep solids.
- PNG viewport export, drag/drop, multi-file picker, import stages, cancel, error recovery and empty state with sample.

## Actual supported formats

- **STL:** binary and ASCII, parsed in a Three.js worker. One mesh, no invented hierarchy. Source units are selected by the user (mm/cm/in).
- **OBJ:** Three.js worker geometry parsing. Optional multi-file **MTL + PNG/JPEG/WebP** texture upload. Select one OBJ together with its MTL and every referenced image. Missing images are reported; model-provided external URLs are not fetched. Materials without accompanying MTL use neutral inspection shading. Names/groups become actual mesh components; hierarchy beyond those meshes is not invented.
- **STEP / STP:** **occt-import-js 0.0.23 / Open Cascade WASM**, in a local classic worker. B-rep input is tessellated before Three.js display. Parser-supplied node hierarchy, names, mesh/face colors and B-rep face-range counts are retained. Open Cascade interprets source units and outputs mm. No backend conversion or upload is used.

Limits: **40 MB combined files, 800,000 output triangles, 200 meshes, two-minute worker timeout**. Balanced STEP tessellation uses bounding-box ratio 0.002; Fine uses 0.0005; angular deflection is 0.35. The ~7.3 MB WASM asset loads only when STEP is opened. Conversion stages are truthful, not simulated percentages; native tessellation does not expose continuous progress. Cancel terminates the worker and preserves the current model.

### Precision and limits

All viewing, dimensions and point distances operate on **triangle geometry**, including tessellated STEP. They are not exact CAD-edge/face metrology. No B-rep editing, constraints, PMI/GD&T, mass properties, assemblies with joints or native CAD history are implemented. External STEP references and unusual exporter metadata are not guaranteed. Generic imported explosion is a visual mesh spread, not a mechanically validated disassembly path. OBJ texture filenames with unusual whitespace/options, unsupported texture types and large texture dimensions are not comprehensively handled. GLB and IGES from the older viewer are not part of this release's supported format set.

The app checks byte/triangle/component limits but is not a hardened hostile-file sandbox. WASM can consume significant memory before output limits are known. Worker parsing/tessellation keeps UI work separate; texture decode, edge generation and GPU upload still occur on the main thread.

Imports are initially temporary and never uploaded. **Save to library** stores byte-exact originals, selected companion assets, thumbnail and inspection state in IndexedDB on this browser profile/device/origin; saved models can reopen after reload. Unsaved imports still disappear. Theme and legacy named views remain in localStorage. Browser eviction/cleared site data can delete the library: use Backup/Restore for durable transfer. No accounts, analytics, cloud sync, deployment or paid service were added. Local fonts, samples and WASM do not require runtime CDNs.

## Run and setup

Node 24 was used. From this app directory:

```sh
npm ci
npm run dev
```

Production:

```sh
npm run build
npm run preview
```

Both use **127.0.0.1:4326** with strict port selection. Stop the preview before starting dev on that port. Serve the app over HTTP, not a file URL, so workers and WASM load correctly. The supplied [Open Cascade assets](public/occt/occt-import-js.js) and [WASM](public/occt/occt-import-js.wasm) must remain beside the [STEP worker](public/occt/step.worker.js). License notices are in the same folder.

Append `?debug=1` while running the development server to expose story progress, explosion, bounds, direction, ID, camera-target, annotation and hierarchy diagnostics. The panel is excluded from production builds by the `import.meta.env.DEV` guard.
